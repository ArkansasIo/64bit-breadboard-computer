# Planned Tools

- `rompack`: package a platform-specific firmware image.
- `post-code`: decode POST/test values.
- `busmon`: interpret compatible logic-analyzer captures.
- `serial-monitor`: connect to the diagnostic console.
- `memory-test`: generate memory diagnostic routines.
- `mmio-check`: validate code against an approved MMIO map.

Keep tools independent of the CPU module where practical.
