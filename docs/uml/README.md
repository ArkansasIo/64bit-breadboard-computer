# UML Diagrams

The `.puml` files use PlantUML syntax. Render with a local PlantUML installation or a compatible editor extension.

- `system.puml`: hardware components and links.
- `boot-sequence.puml`: conceptual boot flow.
- `bus.puml`: logical device transaction.
- `software-stack.puml`: software layering.

These are logical diagrams; they are not pin-level schematics.
