# Breadboard Wiring Guide

Suggested wire colors: red supply, black ground, blue clock/reset, yellow address/control, green data, white debug/interrupt. Color is supplementary—label both ends of every wire.

- Separate major functions onto different boards.
- Keep fast signals short and ground returns sensible.
- Add local decoupling to logic ICs.
- Verify voltage compatibility before connecting modules.
- Never hot-wire unknown CPU pins.
- Photograph each revision and record measurements.

Validation record: board/revision, date, measured rails, clock and reset observations, continuity checks, validated signals, and remaining issues.
