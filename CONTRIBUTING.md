# Contributing

1. Create a branch for each change.
2. Keep hardware assumptions explicit and cite manufacturer documentation in design notes.
3. Do not publish guessed CPU pinouts, unverified voltage levels, or unsafe wiring instructions.
4. Run available assembly checks before opening a pull request.
5. Record source/tool versions and hardware test setup.
6. Separate logical architecture diagrams from validated electrical schematics.

Please describe tested behavior and outstanding limitations in every pull request.
